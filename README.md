# 온음 (Oneum)

**구음장애인을 위한 의도 확인형 의사소통 보조 서비스**

> 발음이 뭉개져도, 내 말은 내가 확정한다.
> AI는 후보를 내고, 확정은 언제나 사용자가 합니다.

온음은 구음장애(마비말장애)인의 발화를 음성인식으로 받아 후보를 그 사람에게 맞춰 정렬하고,
**사용자가 직접 확정한 문장만** 큰 글자와 명료한 음성으로 전달하는 스마트폰 앱입니다.
제9회 D-Tech 공모전 Track 1 출품작이며, 전 흐름이 실기기(iOS)에서 동작합니다.

## 왜 만들었나

- 일반 음성인식은 구음장애 발화에서 절반 가까이 틀립니다 (실측 글자 오류율 42.9%).
- 더 위험한 것은, 틀린 문장을 확신 있는 태도로 출력한다는 점입니다. 사용자의 의도와 다른 말이 그 사람의 말로 전달될 수 있습니다.
- 정부는 2021년 AI Hub에 구음장애 음성 데이터를 구축해 두었지만, 당사자가 실제로 쓸 수 있는 한국어 서비스는 아직 없습니다.

## 핵심 설계

1. **2-엔진 앙상블 인식** — AI Hub 구음장애 데이터로 파인튜닝한 Whisper(정확한 1순위)와 범용 클라우드 STT(다중 후보)를 동시에 호출해 병합합니다.
2. **개인화 재정렬** — 등록한 표현 20~30문장과 교정 이력을 한글 자모 유사도로 대조해 후보 순위를 그 사람에게 맞춥니다. 모델 재학습 없이, 쓸수록 맞춰집니다.
3. **확정 게이트** — 확신해도 재생하지 않고 먼저 묻습니다. 게이트를 지나지 않은 문장은 어떤 경우에도 소리 나지 않습니다. AI가 복원한 문장에는 "제안" 표식이 붙습니다.
4. **연습이 곧 등록** — 연습에서 인식이 검증된 저위험 문장만 "빠른 발화"로 등록되어, 6중 안전 조건 아래 즉시 재생됩니다 (0.5초 미리보기 + 3초 취소권).
5. **기기 안의 개인 데이터** — 서버는 무상태 프록시입니다. 등록 문장·교정 이력은 전부 사용자 휴대폰 안에만 저장됩니다.

## 실측 (검증 전 내부 실측값)

| 모델 | 크기 | CER | WER |
|---|---|---|---|
| whisper-small (범용) | 244M | 42.9% | 69.3% |
| whisper-large-v3-turbo (범용) | 809M | 29.5% | 51.1% |
| **whisper-small 온음 파인튜닝** | **244M** | **18.7%** | **28.6%** |

평가: 학습에 쓰지 않은 화자 9명, 문장형 400클립. 학습에 없던 장애 유형(중풍·뇌부상·뇌성마비·기타)에서도 전부 개선.

## 저장소 구조

```
oneum/mobile     iOS 앱 (React Native · Expo SDK 57 · TypeScript)
oneum/backend    무상태 백엔드 (FastAPI) — 인식 앙상블 · LLM 복원 · AI 대화
oneum/brand      로고·워드마크 생성
asr-poc          파인튜닝 파이프라인 (데이터 정렬 · 학습 · 평가, 재현 스크립트 포함)
제출물            공모전 지원서 · 별지 · 포스터
```

## 실행

```bash
# 백엔드 키 설정 (없으면 mock 모드로 전체 흐름 시연 가능)
cp oneum/backend/.env.example oneum/backend/.env

# ASR 추론 서버 + 백엔드 + Expo 한 번에 기동
cd oneum && ./run-demo.sh
```

파인튜닝 체크포인트와 AI Hub 데이터는 용량·이용 조건상 저장소에 포함하지 않습니다.
재현 절차는 `asr-poc/README.md`와 `asr-poc/results/`의 실측 기록을 참고하세요.
