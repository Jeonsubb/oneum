# 온음 브랜드 자산

로고는 심볼이 아니라 **글자(워드마크)**다. 그리고 폰트로 조판한 것이 아니라 **직접 그린 도형**이다.
그래서 폰트가 없는 PC에서도, 제출용 문서에서도 모양이 그대로 유지된다.

## 생성

```bash
python3 build.py
```

`rsvg-convert`만 있으면 된다 (`brew install librsvg`). 폰트도 파이썬 패키지도 필요 없다.

**PNG를 직접 고치지 말 것.** 색·굵기·비례를 바꿀 일이 생기면 `build.py` 상단의 상수만 고치고
다시 돌린다. 아이콘 여섯 벌을 손으로 관리하면 iOS·안드로이드·파비콘이 반드시 어긋난다.

## 형태

두 글자 모두 초성이 ㅇ이고 가운데에 긴 가로획(온의 ㅗ, 음의 ㅡ)이 나란히 놓인다.
이 구조적 각운을 살려 **가로획을 하나로 이었다.** 두 소리가 한 줄로 이어져 전달된다는 뜻이자,
워드마크를 한 덩어리로 묶어 주는 장치다.

부드러움은 세 가지로 만든다.

| 장치 | 이유 |
|---|---|
| 모든 획 끝과 꺾임을 둥글림 | 각진 끝은 딱딱하고 차갑게 읽힌다 |
| ㅇ의 속공간을 넓게 엶 | 획이 두꺼우면 속이 막혀 답답한 도넛이 된다 |
| ㅁ 모서리 반경을 14로 **고정** | 높이에 비례시키면 완전한 타원이 되어 ㅁ으로 안 읽힌다 |

## 치수

`build.py`의 상수이며, 전부 **잉크 기준**이다. 둥근 획 끝 때문에 획 중심선과 실제 잉크 경계가
`획/2`만큼 어긋나므로, 중심선으로 정의하면 굵기를 바꿀 때마다 비례가 어그러진다.

| 상수 | 값 | 설명 |
|---|---|---|
| `W` | 22 | 획 두께. 20~24 사이에서만 조정한다 |
| `CIRC_D` | 88 | ㅇ 바깥 지름 |
| `SYL_W` | 136 | 음절 하나의 가로 폭 |
| `BOT_H` | 70 | ㄴ·ㅁ 높이. 낮추면 ㅁ이 납작한 알약처럼 보인다 |
| `TICK` | 22 | ㅗ 세로획 중 가로획 위로 드러나는 길이. 더 짧으면 점처럼 보인다 |

## 파일

| 파일 | 용도 |
|---|---|
| `oneum-wordmark.svg` | **기본 로고.** 밝은 배경 |
| `oneum-wordmark-white.svg` | 어두운 배경·브랜드 파랑 위 |
| `oneum-wordmark-mono.svg` | 흑백 인쇄·팩스 |
| `png/` | 위 SVG의 PNG. 벡터를 못 넣는 docx·발표자료용 |
| `../mobile/components/Wordmark.tsx` | **앱에서 쓰는 로고 컴포넌트 (생성물)**. 직접 고치지 말 것 — 좌표를 손으로 옮기면 앱 로고와 브랜드 자산이 갈라진다 |
| `archive/` | 채택하지 않은 이전 안. 되살릴 때를 위해 남겨둠 |

앱 아이콘은 `../mobile/assets/`에 직접 생성된다.

## 색상

| 이름 | 값 | 용도 |
|---|---|---|
| 브랜드 파랑 | `#14508C` | 로고, 강조. `mobile/lib/theme.ts`의 `palette('blue').acc`와 **같은 값이어야 한다** |
| 먹색 | `#191B1E` | 흑백 단색 버전 |

## 사용 규칙

1. **최소 여백**: 로고 높이의 30% 이상을 사방에 비운다.
2. **최소 크기**: 높이 18px. 그 미만에서는 ㅁ의 속공간과 ㅇ의 구멍이 메워진다.
3. **금지**: 비율 변형, 색 임의 변경, 그림자·외곽선·그라디언트, 폰트로 다시 조판하기.
4. **배경**: 밝은 배경에는 파랑, 브랜드 파랑·어두운 배경에는 흰색. 사진 위에는 올리지 않는다.
5. **안드로이드 아이콘**: 원형 마스크에 잘리므로 로고를 캔버스의 53%까지만 키운다
   (지름 66% 안전원 안에 대각선이 들어가야 한다). `build.py`에 계산 근거를 주석으로 남겨 두었다.

## 아직 연결되지 않은 것

`splash-icon.png`는 생성해 두었으나 `expo-splash-screen` 패키지가 없어 앱에 반영되지 않는다.
스플래시가 필요하면 `npx expo install expo-splash-screen` 후 `app.json`의 `plugins`에 설정을
추가해야 한다 (네이티브 빌드 필요 — Expo Go에서는 확인되지 않는다).
