# 파인튜닝 파이프라인 검증 기록 (2026-08-21)

## 목적
AI Hub 구음장애 데이터는 IRB 승인 전까지 잠겨 있다. 데이터가 도착한 뒤에야 파이프라인 버그를
발견하면 본선(11/4) 일정을 잃는다. 따라서 **공개 한국어 데이터로 학습·평가 루프를 미리 검증**한다.

## 검증 데이터 (대체재)
- Zeroth-Korean (CC BY 4.0, 공개 한국어 낭독 음성) 스트리밍으로 120발화만 추출
- train 100 / eval 20, 16kHz mono
- **주의: 정상 발화 데이터다. 구음장애 성능과 무관하며 오직 파이프라인 동작 검증용.**

## 발견·수정한 결함
- `scripts/train.py`가 transformers 5.x에서 실행 불가였음 — `warmup_ratio` 인자 제거됨
  → `warmup_steps`로 수정. **데이터 도착 후 발견했다면 본선 준비 시간을 잃었을 결함.**
- `datasets` 5.x가 오디오 디코딩에 torchcodec을 요구 → `Audio(decode=False)` + soundfile 직접 디코딩으로 회피

## 실측 결과 (M5 Pro 48GB, MPS)

| 항목 | 값 |
|---|---|
| 학습 처리량 | **2.08 발화/초** (100발화 1에폭 = 48초) |
| 평가 처리량 | 20발화 CER/WER 산출 24초 (모델 2개 로드 포함) |
| whisper-small 베이스라인 | CER 19.1% / WER 54.4% |
| 100발화 1에폭 파인튜닝 후 | CER 15.8% / WER 47.2% |

> 위 CER 개선(19.1→15.8)은 **정상 발화 기준 파이프라인 동작 증거일 뿐, 구음장애 개선 근거가 아니다.**
> 기획서·발표에 성능 근거로 인용 금지 (BC-04 표현 원칙).

## 실데이터 소요 추정
- AI Hub 서브셋 1만 발화 × 3에폭 ≈ 4시간 (야간 1회 학습으로 충분)
- 즉 **연산은 병목이 아니다. 병목은 IRB → AI Hub 승인 리드타임.**

## 실험 설계 — 교차 유형 일반화 (확정)

데이터셋은 3개 유형으로 나뉜다. 우리 타겟은 **뇌신경장애(마비말장애: 뇌성마비·뇌졸중·파킨슨)**이나,
서비스는 발화가 불명확한 원인과 무관하게 동작하므로 다른 유형에도 쓰일 수 있어야 한다.
학습은 타겟에 집중하고, 평가로 확장 가능성을 측정한다.

| 유형 | 크기(Training 원천) | 학습 | 평가 |
|---|---|---|---|
| 뇌신경장애 (마비말장애) | 27GB | **O** | O (held-out 화자, **주력 수치**) |
| 언어청각장애 (농인 발화) | 101GB | X | O (일반화) |
| 후두장애 (발성장애) | 226GB | X | O (일반화) |

- 다운로드: 뇌신경장애는 Training+Validation 전부, 나머지 둘은 **Validation만** (용량 절감)
- 실행: `scripts/eval_matrix.py` — 모델 2개 × 평가세트 3개를 한 번에 돌려 마크다운 표 생성
- **해석 규칙: 카테고리 간 절대 CER 비교 금지** (녹음 조건·문장 난이도 상이). 각 카테고리 내 베이스라인 대비 상대 개선율로만 판단
- 결과 시나리오별 해석 (전부 기획서에 사용 가능):
  - 전 유형 개선 → 비정형 발화의 공통 특성 학습, 유형 확장 경로 확보
  - 뇌신경장애만 개선 → 유형별 특화 필요를 데이터로 확인, 로드맵 반영
  - 타 유형 악화 → 도메인 과적합 확인. 서비스가 ASR에만 의존하지 않는 구조(후보 재정렬+폴백)라 사용성은 유지된다는 논거로 전환

## 데이터 도착 시 실행 순서
1. `uv run python scripts/prepare_manifest.py --root data/raw --inspect` — 실제 JSON 키 확인, 필요시 KEY_CANDIDATES 보정
2. `... --method 문장 --eval-speakers 3` — **화자 단위** train/eval 분리 (동일 화자 누출 시 개인화 효과가 새어 수치 무효)
3. `scripts/train.py` → `scripts/eval_wer.py` 로 범용 vs 파인튜닝 쌍체 비교
4. 화자 메타(질병타입·장애등급)로 중증도별 성능 분리 보고 — BC-03(경도~중등도 타겟)의 실증 근거
5. `scripts/eval_matrix.py --models openai/whisper-small checkpoints/<파인튜닝> --sets 뇌신경장애=... 언어청각장애=... 후두장애=...` 로 교차 유형 표 생성
